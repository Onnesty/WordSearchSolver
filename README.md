# Explanation

Made this short project to practice customtkinter and practice programming as a whole.

As the name shows, its an application for solving word search puzzles. It uses Object Oriented Programming in Python as well as algorithms like Depth First Search. This was a fun one to make since at the time I was itching to find a solution on word search puzzles that I keep on stumbling upon in social media, it just seems like I can't find the last couple of words. So that's why I thought of creating this project apart from it being a good project to practice my programming skills. I've tested it on websites that host their own word search problems, and this application works as intended. Though it is a bit inconvenient to use since you have to manually enter the words to find and the letters in the "matrix", and if you mess anything up ( spelling, misconfiguration of height and width ), then you are forced to restart. But overall, it is a pretty neat app that I would use on large word search problems, and I think the app does a good job of clearly explaning itself and what it does to the user.
